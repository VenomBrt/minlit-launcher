Como instalar

  • Windows: abra o .exe e siga os passos. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações → Executar assim mesmo.
  • Linux (AppImage): clique com o botão direito → Propriedades → Permitir executar como programa, ou rode chmod +x Launcher-Minlit.AppImage.
  • Linux (.deb): sudo apt install ./Launcher-Minlit.deb
