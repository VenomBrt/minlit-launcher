# Launcher Minlit

Launcher oficial do servidor de RP **Minlit** (Minecraft 1.21.1 · Fabric).

## Download

**[Página de download](https://venombrt.github.io/minlit-launcher/)**

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | [Launcher-Minlit-Setup.exe](https://github.com/VenomBrt/minlit-launcher/releases/latest/download/Launcher-Minlit-Setup.exe) |
| Linux (qualquer distro) | [Launcher-Minlit.AppImage](https://github.com/VenomBrt/minlit-launcher/releases/latest/download/Launcher-Minlit.AppImage) |
| Ubuntu / Debian | [Launcher-Minlit.deb](https://github.com/VenomBrt/minlit-launcher/releases/latest/download/Launcher-Minlit.deb) |

O launcher se atualiza sozinho quando sai uma versão nova.

## Para a staff

A pasta [`servidor/`](servidor/) controla o que o launcher mostra e baixa: IP do servidor, jornal, procurados, mods e textura.
Veja como editar em [`servidor/LEIA-ME.md`](servidor/LEIA-ME.md).
